# Java Data Structures Practice

This project contains simple Java implementations of basic data structures for learning and practice.

## Included Programs

- `Stack.java` – implementation of a stack using an array
- `SimpleLinearQueue.java` – implementation of a linear queue using an array
- `DoubleEndedLinearQueue.java` – implementation of a double-ended queue using an array

## Project Structure

```text
Java/
├── Main.java
├── BasicDataStructure/
│   ├── Stack.java
│   ├── SimpleLinearQueue.java
│   └── DoubleEndedLinearQueue.java
└── README.md
```

## How to Run

1. Open the project in your Java IDE or terminal.
2. Compile the Java files.
3. Run `Main.java` to test the data structure operations.

Example:

```bash
javac Main.java
java Main
```

## Purpose

This project is intended to help practice:

- Java classes and objects
- Array-based data structures
- Queue and stack operations
- Basic problem-solving in Java
